# ADR Template (spec section 48)

```
ADR-XXX <short title>

Context:
Decision:
Alternatives:
Why:
Consequences:
Risks:
Status: PROPOSED | ACCEPTED | SUPERSEDED
```

The ADR agent documents decisions already taken. It does not invent decisions. If no decision was actually made, the right output is "UNDEFINED DECISION", not a fabricated ADR.
